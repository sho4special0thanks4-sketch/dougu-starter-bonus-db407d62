# 「会社の情報を使わずに作る」チェックリスト

『リフォーム営業13年の私が、Claude Codeで作った道具』読者特典。作る前・作る途中・人に渡す前に、順に確かめます。

## 作り始める前に

- [ ] 自宅・私物のパソコンとアカウントで作っている（職場のパソコンや、職場のアカウントではない）。
- [ ] 勤務先に、AIの利用・副業・出版などについて決まりがないか、自分で確かめた。決まりがあれば、それに従う。
- [ ] 作る道具の目的を、「会社の資料がなくても作れるもの」に絞った。

## AIに渡さないもの

- [ ] お客様の名前・住所・電話番号・メールアドレス・家族構成など、個人が特定できる情報。
- [ ] お客様の図面、見積書、契約書、写真（家や表札が写るもの）。
- [ ] 社内の資料（価格表の原本、仕入れ値、社内マニュアル、様式の原本）。
- [ ] 会社のロゴ、商品名、商品のカタログ画像。
- [ ] パスワード、APIキー、アクセスのためのURL（合言葉の入ったもの）。

## ダミーに置きかえるもの

- [ ] 会社名 →「ひだまり工務店（サンプル）」のような、架空の名前。
- [ ] お客様名 →「サンプル様」。担当者名 → ありふれた下の名前だけ、または「担当 花子」。
- [ ] 住所・電話 → 書かない（「任意」の空欄にする）か、明らかな架空の表記にする。
- [ ] 金額・単価 → 手で計算しやすい、きりのいい数字。画面に「サンプル用の仮の単価」と書く。
- [ ] 間取り・図面 → ツールのテンプレート（2LDKなど）や、自分で描いた架空の図面。
- [ ] 写真 → 自分で撮った、無関係な写真（自宅・公園など）。人や表札を写さない。

## 途中で確かめること

- [ ] AIに「どのファイルを読みましたか」と聞いて、手元の本物の資料を読んでいないか確かめる。
- [ ] 画面・印刷・ファイル名・ファイルの中の説明文に、本物の名前や会社名が残っていないか、検索で探す。
- [ ] ファイルのプロパティ（作成者名など）や、保存した履歴に、本名が残っていないか見る。
- [ ] 画面のスクリーンショットを撮ったら、拡大して、小さな文字（住所・ロゴ・URL）まで見る。

## 人に渡す・公開する前に

- [ ] 公開するページ・ファイルを、初めて開く人の目で、最初から最後まで見る。
- [ ] 実在のメーカーのロゴ・URL・QRコードが、ページの下の方や、2ページ目以降に残っていない。
- [ ] 公開したあとで、公開先の履歴（過去の版）にも、名前などが残っていないか確かめる。
- [ ] 「補助金の数字」「法律の話」には、出典と確認日が付いていて、「最終判断は窓口・専門家で」と書いてある。
